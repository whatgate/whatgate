# WhatGate Backlog（待增强清单）

M1–M6 的核心链路已完成（见 [architecture.md](architecture.md) 路线图）。本清单汇总后续增强项，供规划与贡献者认领。

**优先级**：`P0` 关键（安全/正确性底线）· `P1` 重要（可用性/完整性）· `P2` 改进（体验/优化）
**状态**：`todo` 待做 · `partial` 部分已有基础

---

## A. 安全与信任加固（项目立身之本，优先）

| 优先级 | 项 | 说明 |
|---|---|---|
| P0 | **签名注册** | 目前节点可用任意 `peerID` 向协调器注册/加入小网，能冒充他人。应要求用 libp2p 私钥签名注册/入群请求，协调器校验签名 == PeerID。 |
| P1 | **小网操作鉴权** | `/group/join`·`/group/endorse` 目前无鉴权。应校验发起者确为该组成员/创建者，背书需组管理员。 |
| P1 | **声誉事件驱动 + 衰减 + 持久化** | 现有 `trust.Reputation` 只是存储；需定义"什么行为加/减分"（出口成功/超时/被举报…）、随时间衰减、并落盘。 |
| P1 | **ExitGuard 声誉门槛** | 出口策略加"只服务声誉≥阈值的请求方"（`Policy` 增字段 + 授权时校验）。 |
| P2 | **抗女巫 / 协调器限流** | 邀请制之外，加注册/入群频率限制、异常行为检测，防批量小号。 |

## B. 出口治理增强（ExitGuard）

| 优先级 | 项 | 说明 |
|---|---|---|
| P1 | **连接留痕持久化（可追溯审计）** | 出口侧把"谁、何时、连了什么"结构化落盘，配合邀请链做事后追责。 |
| P1 | **威胁情报域名源** | 定期拉取已知恶意域名清单并入 `BlockedDomains`，拦明显恶意流量。 |
| P2 | **带宽级限额与熔断** | 当前限并发连接数；补带宽配额 + 异常流量模式自动熔断并降请求方声誉。 |
| P2 | **按请求方限速** | 单请求方速率/连接上限，防单点滥用。 |

## C. 组网 / 协调 / 中继

| 优先级 | 项 | 说明 |
|---|---|---|
| P1 | **状态持久化** | 目录/邀请/信任图/声誉现全在内存，协调器重启即丢。接入嵌入式存储（如 SQLite/BoltDB）。 |
| P1 | **跨 NAT 真实验证** | 用两台不同网络的机器实测 DCUtR 打洞与 AutoRelay 自动预约（回环无法覆盖）。 |
| P2 | **协调器高可用 / 去中心目录** | 首版单实例；后续多实例或渐进式 DHT 目录，消除单点。 |
| P2 | **中继资源限制** | 给 Circuit Relay 加带宽/时长/预约数配额，防中继被滥用。 |

## D. 传输 / 选路

| 优先级 | 项 | 说明 |
|---|---|---|
| P1 | **UDP 支持** | 现仅 TCP（SOCKS5 CONNECT）。补 SOCKS5 UDP ASSOCIATE / QUIC，覆盖 DNS-over-UDP、游戏、音视频。 |
| P2 | **选路精细化** | 延迟周期性重探 + 移动平均；可配的加权综合评分（信任/延迟/负载权重）。 |
| P2 | **DNS 策略** | 明确并可配 DNS 解析位置（出口侧解析利于解锁）；文档化防 DNS 泄漏。 |

## E. TUN 全局模式（桌面）

| 优先级 | 项 | 说明 |
|---|---|---|
| P1 | **自动路由 / 排除自身流量** | 现需手动配 IP/路由，且必须手动把出口/协调器连接排除出 TUN（否则回环）。应在 `internal/tun` 自动下发。 |
| P2 | **UDP/DNS 分流、IPv6** | 全局模式下的分流规则与 IPv6 支持。 |
| P2 | **驱动打包与安装器** | 打包 `wintun.dll`、各平台安装/权限引导。 |

## F. 移动端（Android / iOS）

| 优先级 | 项 | 说明 |
|---|---|---|
| P1 | **gomobile 瘦封装 + bind** | 暴露 `Start(configJSON, tunFD)/Stop()`，产出 Android `.aar` / iOS `.xcframework`（复用核心 + tun2socks fd 后端）。 |
| P1 | **系统 VPN 接入** | Android `VpnService` / iOS `NEPacketTunnelProvider`（iOS 需 Network Extension 权限与开发者账号）。 |
| P1 | **移动 UI 外壳** | 地区选择、出口开关、小网管理、首启动信任向导。 |

参见 [tun-and-mobile.md](tun-and-mobile.md)。

## G. 桌面 UI 与体验

| 优先级 | 项 | 说明 |
|---|---|---|
| P1 | **桌面外壳** | 系统托盘 + 本地 Web 控制台（或 Wails/Tauri）：状态、地区、出口开关、小网管理。 |
| P1 | **图形化首启动信任向导** | 解释"成为出口/用陌生出口"的风险，让用户选信任范围档位（CLI 现以 `-trust-scope` 无默认体现）。 |
| P2 | **配置文件支持** | 现全用命令行 flag；补 YAML/JSON 配置。 |
| P2 | **小网管理 UX** | 退组、移除成员、撤销背书等操作与界面。 |

## H. 工程 / 发布 / 运维

| 优先级 | 项 | 说明 |
|---|---|---|
| P1 | **CI** | PR 上自动 `go test ./...` + `go vet` + `gofmt` 检查（含 `-tags tun` 构建）。 |
| P1 | **交叉编译与发布** | 一键出 Windows/macOS/Linux 二进制，挂 GitHub Releases，代码签名。 |
